# MLR_Models_TPAI_2025
Literature for multi-vocal literature review of models for testing process assessment and improvement
This source includes following excel files: 
**File 1: "MLR_TPAI_2025_Literature_References.xlsx**
This sheet includes list of literature that was found as a result of search string. Overall 907 studies were found out of 818 studies were exluded as per inclusion/exclusion criteria on the basis of Year, Language, Availability and Content. Remaining studies were filtered to check duplications. Out of 89, 72 uniques studies were left. The Citations of these studies are provided here.
**File 2: "MLR_TPAI_2025_Model_Definitions**
The file contains references to model definitions or the closest documentation found regarding model definition. The purpose was to find formal model(s) documentation or studies that provide information about the structure of the models.  
**File 3: "TMMi 2 maturity level assessment by TPI NEXT.xlsx**
A detailed assessment of TMMi maturity level 2 according to TPI NEXT maturity model.
**END**
